BarLabel - Windows Service (Service จริง)
==========================================

Executable ปัจจุบัน:
D:\Golang\scanbar\barLabel.exe

สำคัญมาก
--------
โปรแกรม Go ที่เรียก net/http.ListenAndServe() แบบปกติ ไม่ใช่ Windows Service
การใช้ sc.exe create กับ executable ปัจจุบันเพียงอย่างเดียวจะไม่ทำให้โปรแกรม
กลายเป็น Service และอาจเริ่มแล้วหยุดทันที

ต้องแก้และ build barLabel.exe ให้รองรับ Windows Service ก่อน
(เช่น ใช้ golang.org/x/sys/windows/svc หรือไลบรารี Go สำหรับ Windows Service)
จากนั้นจึงลงทะเบียน executable ที่รองรับ Service ด้วย sc.exe ได้

ขั้นตอนหลังจาก build executable ที่รองรับ Windows Service แล้ว
---------------------------------------------------------------

1. เปิด CMD แบบ Run as administrator

2. สร้าง Service ชื่อ BarLabel:

sc.exe create BarLabel binPath= "D:\Golang\scanbar\barLabel.exe" start= auto DisplayName= "BarLabel"

3. ตั้งคำอธิบาย (ไม่บังคับ):

sc.exe description BarLabel "BarLabel web application"

4. เริ่ม Service:

sc.exe start BarLabel

5. ตรวจสอบสถานะ:

sc.exe query BarLabel

สถานะที่ต้องการคือ STATE: 4 RUNNING

คำสั่งจัดการ Service
--------------------

หยุด:

sc.exe stop BarLabel

เริ่มใหม่ (หยุดก่อน แล้วเริ่ม):

sc.exe stop BarLabel
sc.exe start BarLabel

ลบ Service (หยุดก่อน):

sc.exe stop BarLabel
sc.exe delete BarLabel

ข้อกำหนดก่อนใช้งานจริง
-----------------------

- ต้อง build executable ที่รองรับ Windows Service ก่อน ห้ามใช้คำสั่ง sc.exe create
  กับ executable ปกติแล้วคาดหวังว่าจะทำงานเป็น Service ได้ทันที
- Service ทำงานด้วยบัญชีระบบโดยค่าเริ่มต้น หากต้องเชื่อมต่อ SQL Server หรืออ่านไฟล์
  ที่จำกัดสิทธิ์ ให้ตั้ง Log On account ของ Service เป็นบัญชี Windows ที่เหมาะสม
- โปรแกรมปัจจุบันอ่าน .env และไฟล์ index.html, style, js, font ด้วย relative paths
  ต้องแก้โปรแกรมให้กำหนด working directory เป็น D:\Golang\scanbar หรือเปลี่ยนเป็น
  absolute paths ก่อนรันเป็น Service ไม่เช่นนั้นอาจหาไฟล์ไม่เจอ
- ต้องมีไฟล์ .env ที่จำเป็นในตำแหน่งที่โปรแกรมอ่านได้ ห้าม commit secret ลง Git
- เมื่อ Service ทำงานแล้ว ทดสอบ API เช่น http://localhost:8080/api/health
- หาก Service เริ่มไม่สำเร็จ ให้ตรวจ Event Viewer > Windows Logs > Application
  และเพิ่ม logging ลงไฟล์สำหรับตรวจสอบ startup errors

หมายเหตุ
-------
ไฟล์นี้เป็นคู่มือการติดตั้งหลังจากโปรแกรมรองรับ Windows Service แล้ว
ยังไม่ใช่การเปลี่ยน barLabel.exe ให้รองรับ Service ด้วยตัวมันเอง
