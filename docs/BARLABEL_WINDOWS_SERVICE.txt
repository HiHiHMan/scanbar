BarLabel - ติดตั้งเป็น Windows Service จริง
==============================================

ชื่อ Service:
BarLabel

ตำแหน่งโปรแกรม:
D:\Golang\scanbar\barLabel.exe

การจัดการ Windows Service ใช้ github.com/kardianos/service ตามตัวอย่างใน
docs/main.go โดยยังคง API, SQL Server และไฟล์หน้าเว็บของ BarLabel ไว้ตามเดิม

1. Build โปรแกรม
----------------

เปิด CMD แล้วรัน:

cd /d D:\Golang\scanbar
go mod tidy
go build -o barLabel.exe .

ตรวจสอบว่าไฟล์นี้มีอยู่:
D:\Golang\scanbar\barLabel.exe

ตรวจสอบว่าไฟล์ .env อยู่ในโฟลเดอร์เดียวกับ EXE และมีค่า DB_USER, DB_PASSWORD
รวมถึงค่า DB_HOST, DB_PORT, DB_NAME ตามการตั้งค่าของระบบ

2. เปลี่ยนจาก Service แบบเดิม
------------------------------

เปิด CMD แบบ Run as administrator และหยุด Service เดิมก่อน:

sc.exe stop BarLabel
sc.exe delete BarLabel

ถ้า Service เดิมไม่มีอยู่แล้ว ให้ข้ามคำสั่งที่แจ้งว่าไม่พบ Service
รอให้ Windows ลบ Service เดิมเสร็จก่อนดำเนินการต่อ

3. ติดตั้งและเริ่ม Service
--------------------------

เปิด CMD แบบ Run as administrator:

cd /d D:\Golang\scanbar
barLabel.exe install
barLabel.exe start

คำสั่งจัดการ Service ใช้รูปแบบเดียวกับ docs/main.go:

barLabel.exe install
barLabel.exe start
barLabel.exe stop
barLabel.exe uninstall

4. ตรวจสอบสถานะ
---------------

sc.exe query BarLabel

ต้องเห็น:
STATE : 4 RUNNING

ทดสอบ API ในเครื่อง:
http://localhost:8080/api/health

5. หมายเหตุสำคัญ
----------------

- ต้อง Build EXE ใหม่จากโค้ดล่าสุดก่อนติดตั้ง Service
- โปรแกรมตั้ง working directory เป็นโฟลเดอร์ของ EXE จึงอ่าน .env, index.html,
  style, js และ font จาก D:\Golang\scanbar ได้
- Service ใช้บัญชี LocalSystem เป็นค่าเริ่มต้น หากนโยบายหรือสิทธิ์ SQL Server
  ต้องใช้บัญชี Windows เฉพาะ ให้เปลี่ยนบัญชีที่แท็บ Log On ของ Service
- การตั้งค่า SQL Login ใน .env ต้องมี DB_USER และ DB_PASSWORD
- อย่ารัน install ซ้ำหาก Service BarLabel ติดตั้งอยู่แล้ว
- ถ้า Service ไม่เริ่ม ให้ตรวจสอบ Event Viewer, .env และการเชื่อมต่อ SQL Server
